宜中校園服務平台｜AI 虛擬資料操作 DEMO v0.3.0

使用方式
1. 解壓縮整個資料夾。
2. 雙擊「啟動DEMO.cmd」。
3. 瀏覽器會開啟與正式系統同版型的校園服務平台。

若學校電腦封鎖 CMD，也可直接雙擊 index.html；大部分功能仍可操作。

展示範圍
- 校園服務平台首頁
- 學生服務預約、取消、我的預約、志工履歷
- 捐血活動報名與個人紀錄
- 教職員健康教育前後測與教材頁
- 管理後台：點名、預約、時段、捐血、前後測、履歷列印、郵件中心

安全說明
- 全部姓名、學號、班級、Email 與活動紀錄均為 AI 虛擬資料。
- 不連接 Google Sheet、Apps Script 或正式校務資料。
- EMAIL 只做畫面與紀錄模擬，不會實際寄信。
- 關閉瀏覽器後資料仍保存在該瀏覽器；如需重置，可在網址列開發者工具執行 YLSH_DEMO_RESET()，或清除該網站資料。
